# SFL-Clause-Analysis

Masters project - Arti Patel - 21250524

Project consists of:

    -models: Folder contains schemas
    -routes/DB_Routes: Contains all routes and js files in relation to API calls
    -Views: Contains all the UI part of the application
    -apiDocumentation : Contains a JSON file, which can be imported in Postman to view the API Collection
    -uml : All the diagram of databse and user-flow

To Use:

To clone and run this repository you'll need [Git](https://git-scm.com), [Node.js](https://nodejs.org/en/download/) (which comes with [npm](http://npmjs.com)) and [MongoDB] (https://www.mongodb.com/try/download/compass/)installed on your computer.
